# Skywalker Crypto RS

Mobile Crypto-Relative-Strength-Web-App für iPhone/GitHub Pages.

Die Anwendung visualisiert Relative Strength und Marktbreite im Kryptomarkt und enthält unter anderem ETH/BTC- sowie Breadth-orientierte Auswertungen. Die aktuelle Implementierung liegt in `index.html`.

## Projektworkflow

Technische Source of Truth:
- Code im Repository
- `docs/PROJECT.md`

Produkt-Source-of-Truth:
- Notion-Seite `Skywalker Crypto RS`

Für Codex und Claude Code gilt derselbe Standardworkflow. Der Kurzauftrag lautet:

> Notion Sync durchführen

Details stehen in `AGENTS.md`, `CLAUDE.md` und `docs/PROJECT.md`.
